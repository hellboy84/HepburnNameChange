# ヘボン式ローマ字氏名変換ツール

ヘボン式ローマ字で書かれた複数の氏名を，カタカナ / ひらがなに一括変換するツールです。
逆方向（カナ → ヘボン式）の変換にも対応しています。

- ブラウザだけで動作し，インストールは不要です
- 入力した氏名が外部に送信されることはありません（HTML 1ファイルで完結し，外部通信を行いません）

## 使い方

1. [ページ](https://hellboy84.github.io/HepburnNameChange/)を開き，変換の方向をタブで選びます
2. 氏名を1行に1名ずつ入力します（姓と名はスペースで区切ります）
3. 必要に応じてオプションを選び，「結果をコピー」でコピーします

ダウンロードして使う場合は，`index.html` をご自身のブラウザで開くだけで動作します。

## 変換例

| 入力 | 出力 |
|---|---|
| Hanako SUZUKI | スズキ ハナコ（氏名を反転） |
| Taro YAMADA | ヤマダ タロ（※タロ(ウ) の可能性を表示） |
| Yuuko SATOH | サトウ ユウコ |
| yuko | ユコ（※ユ(ウ)コ の可能性を表示） |
| ヤマダ タロウ | Taro YAMADA ／ Taroh YAMADA ／ Tarō YAMADA |
| ホンマ ケンタ | Kenta HOMMA ／ Kenta HONMA |

## 主な機能

- ヘボン → カナ / カナ → ヘボン の両方向の変換に対応
- 複数行の一括変換
- カタカナ / ひらがな の切り替え
- 氏名の順序の反転，区切り文字の選択
- 長音が省略されていそうな箇所に印を表示
- ヘボン式の長音や撥音の複数の表記に出力対応
  - 長音：省略（Ono）/ h表記（Ohno）/ マクロン（Ōno）
  - 撥音：b・m・p の前の「ン」を m / n にするかを選択（Namba / Nanba）
- ヘボン式の出力時に大文字・小文字のバリエーションに対応：Taro YAMADA / Taro Yamada / TARO YAMADA
- 結果のコピー，表形式（タブ区切り）でのコピー

## 注意事項

- 漢字には対応していません
- ヘボンからカナを確定できない場合があります（例：Ono は「オノ」と「オオノ」のどちらもあり得る）
- 長音の注記はあくまで目安です
- 設定と入力内容は，次回のためにお使いのブラウザ内（localStorage）に保存されます
